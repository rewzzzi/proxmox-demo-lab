# Proxmox Demo Lab — Стенды Демоэкзамена (КИМ 09.02.06)

Автоматизированный комплекс развертывания лабораторных стендов для проведения Демонстрационного экзамена по специальности **09.02.06 «Сетевое и системное администрирование»** (в соответствии со спецификацией **КИМ 09.02.06-1-2027**).

---

## Архитектура и возможности

- **2 независимых пула и 2 логина на каждого студента:**
  - **Модуль 1 (Задание 1 — «Настройка сетевой инфраструктуры», 1 ч):**
    - Логин: `student01-m1@pve` | Пул: `pool-student-01-m1` (VMID: 200..207)
    - Чистый стенд (пустые ОС). Студент настраивает всё с нуля: адресацию, VLAN 100/200/999, OSPF с аутентификацией MD5, GRE-туннель, NAT, пользователей `sshuser` и `net_admin`, DNS и DHCP.
  - **Модуль 2 (Задание 2 и 3 — «Организация сетевого администрирования» и «Эксплуатация», 2.5 ч):**
    - Логин: `student01-m2@pve` | Пул: `pool-student-01-m2` (VMID: 210..217)
    - Преднастроенный стенд в строгом соответствии со стр. 51–52 КИМа (Samba DC на BR-SRV, готовая маршрутизация и туннели, предсозданные пользователи, и 2 дополнительных накопителя по 1 ГБ на HQ-SRV для создания RAID 0 под NFS).
- **Свободный выбор порядка работы:**
  - Студент может в любой момент переключаться между модулями или выполнять их в любом порядке.
- **Полная сетевая изоляция:**
  - У каждого модуля каждого студента свой диапазон Linux-мостов (`vmbr1XX1..9` для Модуля 1 и `vmbr2XX1..9` для Модуля 2). Трафик, DHCP и OSPF разных модулей и студентов никогда не пересекаются, даже если запущены все 16 машин одновременно.
- **Мгновенное развертывание (Linked Clones):**
  - Шаблоны Модуля 1 (900–907) и Модуля 2 (910–917) создаются один раз.
  - Развертывание 16 машин студента занимает всего **~15–20 секунд**.
- **Мгновенный сброс (Reset):**
  - При создании автоматически фиксируется снимок `lab-initial` в выключенном состоянии. В случае фатальной ошибки стенд откатывается за 2 секунды.
- **Автоматическая печать карточек с паролями:**
  - Все логины и случайные пароли сохраняются в файл `/root/students_credentials.txt`.

## Быстрый старт

### Вариант 1: Установка через git
```bash
git clone https://github.com/rewzzzi/proxmox-demo-lab.git /root/proxmox-demo-lab
cd /root/proxmox-demo-lab
python3 demo-lab.py
```

### Вариант 2: Запуск одной строчкой
```bash
curl -sSL https://raw.githubusercontent.com/rewzzzi/proxmox-demo-lab/main/install.sh | bash
```

## Меню управления

```text
=================================================================
    УПРАВЛЕНИЕ СТЕНДАМИ ДЕМОЭКЗАМЕНА (КИМ 09.02.06-1-2027)
          (2 отдельных пула и логина на студента)
=================================================================
 1. СОЗДАТЬ/ОБНОВИТЬ ЭТАЛОННЫЕ ШАБЛОНЫ (900-907 / 910-917)
 2. Развернуть стенды для ОДНОГО студента (M1 / M2 / Оба)
 3. МАССОВОЕ развертывание для группы 1-20 (M1 / M2 / Оба)
-----------------------------------------------------------------
 4. Создать контрольные снимки для ОДНОГО студента
 5. Создать контрольные снимки МАССОВО (для группы)
-----------------------------------------------------------------
 6. Сбросить стенд студента к снимку (Reset)
 7. Массовый сброс стендов группы (Reset группы)
 8. Выключить все машины группы (Stop all)
 9. Удалить стенды студента (ВМ, пулы, логины)
10. Показать карточки логинов и паролей (credentials.txt)
 0. Выход
=================================================================
```
