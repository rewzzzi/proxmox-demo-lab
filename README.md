# Proxmox Demo Lab — Стенды Демоэкзамена (КИМ 09.02.06)

Автоматизированный комплекс развертывания лабораторных стендов для проведения Демонстрационного экзамена по специальности **09.02.06 «Сетевое и системное администрирование»** (в соответствии со спецификацией **КИМ 09.02.06-1-2027**).

---

## Архитектура и возможности

- **2 независимых пула и 2 логина на каждого студента (Стенд А и Стенд B):**
  - **Стенд А (Модуль 1 — «Настройка сетевой инфраструктуры», 1 ч):**
    - Пул: `DE_09.02.06-2027_stand_A-1`
    - Комментарий: `Стенд участника демэкзамена "Сетевое и системное администрирование" А-1`
    - Логин: `student01-A@pve`
    - Диапазон VMID: **10101 – 10108** *(1 = Модуль 1, 01 = Студент, 01..08 = Машины)*
    - Чистый стенд (пустые ОС). Студент настраивает всё с нуля: адресацию, VLAN 100/200/999, OSPF с аутентификацией MD5, GRE-туннель, NAT, пользователей `sshuser` и `net_admin`, DNS и DHCP.
  - **Стенд B (Модуль 2 — «Организация сетевого администрирования» и «Эксплуатация», 2.5 ч):**
    - Пул: `DE_09.02.06-2027_stand_B-1`
    - Комментарий: `Стенд участника демэкзамена "Сетевое и системное администрирование" Б-1`
    - Логин: `student01-B@pve`
    - Диапазон VMID: **20101 – 20108** *(2 = Модуль 2, 01 = Студент, 01..08 = Машины)*
    - Преднастроенный стенд по стр. 51–52 КИМа (Samba DC на BR-SRV, готовая маршрутизация и туннели, предсозданные пользователи, и 2 дополнительных накопителя по 1 ГБ на HQ-SRV для создания RAID 0 под NFS).
- **Цветные закладки (теги) в интерфейсе Proxmox:**
  - `ISP`, `HQ-RTR`, `BR-RTR` → тег `router` (зеленый кружок)
  - `HQ-SRV`, `BR-SRV` → тег `server` (песочно-желтый кружок)
  - `HQ-CLI` → тег `client` (коричнево-оранжевый кружок)
  - `HQ-SW` → тег `switch`
  - `BR-FW` → тег `firewall`
- **Встроенная диагностика и аудит стендов (Пункт 4):**
  - Эксперт может в один клик проверить готовность стенда конкретного студента или всей группы (1–20).
  - Скрипт опрашивает Proxmox и выводит статус: пулы ресурсов, учетные записи, права ACL, активность сетевых мостов `vmbr`, целостность виртуальных машин, наличие дисков и контрольных снимков `lab-initial`.
- **Автоматический мониторинг хранилища:**
  - Постоянный контроль заполнения LVM-Thin пула `pve/data` с предупреждением при превышении порога, предотвращающий падение импорта дисков из-за нехватки места.
- **Полная сетевая изоляция:**
  - У каждого модуля каждого студента свой диапазон Linux-мостов (`vmbr1XX1..9` для Стенда А и `vmbr2XX1..9` для Стенда B). Трафик, DHCP и OSPF разных модулей и студентов никогда не пересекаются, даже если запущены все машины одновременно.
- **Мгновенное развертывание (Linked Clones):**
  - Шаблоны Модуля 1 (900–907) и Модуля 2 (910–917) создаются один раз.
  - Развертывание 16 машин студента занимает всего **~15–20 секунд**.
- **Мгновенный сброс (Reset):**
  - При создании автоматически фиксируется снимок `lab-initial` в выключенном состоянии. В случае фатальной ошибки стенд откатывается за 2 секунды.
- **Автоматическая печать карточек с паролями:**
  - Все логины и сгенерированные пароли сохраняются в файл `/root/students_credentials.txt`.

## Меню управления

```text
 1. СОЗДАТЬ/ОБНОВИТЬ ЭТАЛОННЫЕ ШАБЛОНЫ (900-907 / 910-917)
 2. Развернуть стенды для ОДНОГО студента (Стенд А / B / Оба)
 3. МАССОВОЕ развертывание для группы (Стенд А / B / Оба)
 4. Проверить стенды студента / группы (ДИАГНОСТИКА И СТАТУС)
 5. Создать контрольные снимки для ОДНОГО студента
 6. Создать контрольные снимки МАССОВО (для группы)
 7. Сбросить стенд студента к снимку (Reset)
 8. Массовый сброс стендов группы (Reset группы)
 9. Выключить все машины группы (Stop all)
10. Удалить стенды студента (ВМ, пулы, логины)
11. Показать карточки логинов и паролей (credentials.txt)
 0. Выход
```

## Быстрый старт на Proxmox VE

### Запуск одной строчкой:
```bash
curl -sSL https://raw.githubusercontent.com/rewzzzi/proxmox-demo-lab/main/install.sh | bash
```

### Или вручную через Git:
```bash
git clone https://github.com/rewzzzi/proxmox-demo-lab.git /root/proxmox-demo-lab
cd /root/proxmox-demo-lab
python3 demo-lab.py
```

## Порядок работы на площадке:
1. **Пункт 1 в меню:** Создать эталонные шаблоны (сначала для Модуля 1, затем для Модуля 2).
2. **Пункт 3 в меню:** Массово развернуть стенды для группы (например, с 1 по 20 студента).
3. **Пункт 4 в меню:** Запустить диагностику группы (проверить `1-20`), убедиться, что все 16 ВМ на студента и снимки `lab-initial` имеют статус `[✓ ГОТОВ К СДАЧЕ]`.
4. **Пункт 11 в меню:** Распечатать / раздать карточки логинов и паролей студентам.
